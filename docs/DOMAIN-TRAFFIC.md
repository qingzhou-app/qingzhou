# 月度域名流量

从 build33 开始，首页「流量统计 → 月度域名流量」和连接页工具栏可查看真实载荷的月度排行。默认本月代理，可切换月份、代理/直连/全部，按总量、上传或下载排序，搜索主域名。此前的域名分析只有连接次数，不能补算历史字节。

## 统计来源与边界

xray dispatcher 完成嗅探和路由后，为 `tun-in → proxy/direct` 用户链路包装 reader/writer。读取上传载荷、成功写回下载载荷；排除内部 DNS、探针及拒绝出口。没有经过轻舟的流量不计入。未知域名归「未识别域名」，超过容量归「其他域名」，保留其上下行和路由总量。

此处是应用载荷观测，不是订阅计费账单。订阅倍率、协议封装、加密、TCP 重传、其他设备，以及部分写入失败的字节，都会造成差异。连接到 CDN 域名不一定能归因到具体 App；无法从这一榜单精确推断哪个 App 的全部用量。

内核按进程累计，通过已有本地 metrics 接口采样。隧道扩展约每 10 秒把累计值增量和去重基线原子保存，主 App 只读；退出主 App 不影响记录。重复读取、主 App 重开和扩展进程重启不重复累计。停止或异常退出可能漏最后数秒，磁盘写失败会在后续样本重试；已有文件无法解码时保留原文件并停止覆盖。

每次增量按采样时本地自然月归档，临近月界最多有一个采样间隔的偏移；长时间无法落盘再恢复时，未保存增量会归到恢复时的月份。页面展示开始记录、最后更新和归档时区。新版本安装后需重启 VPN 才会加载新扩展，旧月份无记录不代表当时没有消费。

## 容量与隐私

- 内核整个进程最多 512 个域名/路由组合，再加未知/其他桶；达到上限后新域名归其他，旧域名继续更新。长期隧道不会无限增长。
- 本地账本保留最近 6 个自然月，每月最多 512 个主域名，再加未知/其他桶。基线只保留主域名聚合。
- App Group 的 `domain-traffic-history.json` 是单独的本机文件，不进入配置快照或 iCloud vault；标记排除系统备份。iOS 首次解锁后可在锁屏继续写入。
- 不记录路径、查询参数、源地址、凭据或连接明细，不自动上传任何流量报告。

## 开发验证

生成源是 `scripts/patches/xray-core/qingzhou_domain_traffic*.go` 和 `scripts/apply-domain-traffic-patch.py`。`build-libxray.sh` 应用补丁、运行行为测试，再构建 xcframework；请勿直接修改生成的 framework。可通过 `LIBXRAY_DIR` 使用隔离 checkout、`LIBXRAY_OUTPUT_DIR` 指定临时产物。

Swift 回归：`swift test --filter 'DomainTrafficLedgerTests|DomainTrafficRecorderTests'`。覆盖累计去重、进程重启、跨月、本地时区、回退/旧样本、容量守恒、六个月保留、坏文件保护、落盘失败重试。Go 测试覆盖方向、生命周期转发、探针排除、失败写入、容量/未知和并发快照；`go test -race ./app/dispatcher -run TestQingzhouDomain -count=1` 在已打补丁的隔离 core 中运行。

真机需核对：代理/直连分流的域名字节增长，主 App 退出后继续保存，重开不重复计数；查看未知/其他及无记录月份状态；检查最新记录时间。工程测试和编译通过不能代替真机验收。
